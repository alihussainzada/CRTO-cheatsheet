MS SQL (Structured Query Language) Server is Microsoft's proprietary relational database management system.

## 1. Enumeration
### SPNs
One way to enumerate SQL server instances is to query for the SPNs that are used to support Kerberos authentication. This will give you the hostname of the SQL servers and the service accounts that are used to run them
```
ldapsearch (&(samAccountType=805306368)(servicePrincipalName=MSSQLSvc*)) --attributes name,samAccountName,servicePrincipalName
```

### Port scanner
If they haven't been configured to support Kerberos authentication, then scanning for open ports [known](https://learn.microsoft.com/en-us/sql/sql-server/install/configure-the-windows-firewall-to-allow-sql-server-access) to be used by MS SQL server may be a suitable alternative.
```
portscan 10.10.120.0/23 1433 arp 1024
```

## 2. SQL Server Information

- Public role: Minimum role for further SQL interaction; can retrieve information.
    - `sql-info <host-server>` — gathers server, domain, service account, authentication, version, OS, current login, `sysadmin` status, and active sessions.

- `sql-whoami <host-server>`: Identifies the current login, mapped database user, and database/server roles and permissions.
    - Interesting roles: `sysadmin`, `serveradmin`, `securityadmin`, `setupadmin`, and `dbcreator`.

- SQL Browser (UDP/1434): Can reveal server name, instance name, version, and TCP port without SQL instance roles.
	 - `sql-1434udp <IP>`

- `sql-query <server> "<query>"`: Executes custom SQL queries; the `public` role may permit querying, depending on permissions.


## 3. Finding User with Sys admin access 
We can find a user with admin level access in any db with the following query
```
ldapsearch (&(samAccountType=268435456)(|(name=*SQL*)(name=*DB*)(name=*Database*))) --attributes distinguishedName,member
```
## Querying Databases
SQL-BOF provides commands for database enumeration and data hunting:

|Command|Purpose|
|---|---|
|`sql-databases`|Lists available databases.|
|`sql-tables`|Lists tables in a specified database.|
|`sql-columns`|Lists columns in a specified table.|
|`sql-search`|Searches database columns for a keyword.|
