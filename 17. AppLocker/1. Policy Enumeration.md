AppLocker policies can be enumerated from two locations: 
1. Directly from the GPO 
2. From the local registry of a computer to which they're applied.  

## Registry
If you have console access to a protected machine. They are stored in `HKLM\Software\Policies\Microsoft\Windows\SrpV2` with each policy type in their own respective subkey.  You can read them manually by just querying the registry, where each rule is stored as an XML string.
```
Get-ChildItem 'HKLM:Software\Policies\Microsoft\Windows\SrpV2'
```

```
Get-ChildItem 'HKLM:Software\Policies\Microsoft\Windows\SrpV2\Exe'
```

You can also use the native AppLocker cmdlet, [Get-AppLockerPolicy](https://learn.microsoft.com/en-us/powershell/module/applocker/get-applockerpolicy?view=windowsserver2025-ps), which parses the rules in a more readable manner.
```
$policy = Get-AppLockerPolicy -Effective

$policy.RuleCollections
```


## GPO
When you have a Beacon running on an unprotected machine, but you're trying to move laterally to a protected machine. The best way of finding the correct GPO is to enumerate them all and go based on their names.

Alternatively, you can walk through each container in SYSVOL (e.g. `\\contoso.com\SYSVOL\contoso.com\Policies`) and look for `Registry.pol` files in the **Machine** directory.

```
ldapsearch (objectClass=groupPolicyContainer) --attributes displayName,gPCFileSysPath
```
```
ls \\contoso.com\SysVol\contoso.com\Policies\{8ECEE926-7FEE-48CD-9F51-493EB5AD95DC}\Machine
```
```
download \\contoso.com\SysVol\contoso.com\Policies\{8ECEE926-7FEE-48CD-9F51-493EB5AD95DC}\Machine\Registry.pol
```

Once sync'd to your desktop, the file can be read using the `Parse-PolFile` cmdlet from the [GpRegistryPolicy](https://www.powershellgallery.com/packages/GPRegistryPolicy/0.3) module.
```
Parse-PolFile -Path .\Desktop\Registry.pol
```
