Active Directory Certificate Services (ADCS) is a Windows role for issuing and managing public key infrastructure (PKI) certificates used in secure communication and authentication protocols.  It integrates with Active Directory Domain Services (ADDS) to provide:

- Confidentiality through encryption.
- Integrity through digital signatures.
- Authentication by associating certificate keys with the computer and user accounts in a forest or domain.

### Certificate Templates
Certificate templates allow administrators to issue certificates that have been preconfigured for specific purposes - they are basically sets of rules and policies to be applied against incoming certificate requests.

## Enumeration
There are many tools to do this, but I'm going to demonstrate [Certify](https://github.com/GhostPack/Certify).  In the first instance, the `enum-cas` command will return information about CA and sub-CA's in the domain.
```
execute-assembly C:\Tools\Certify\Certify\bin\Release\Certify.exe enum-cas --quiet
```

CA's themselves can be vulnerable to attack too - as this output highlights.
