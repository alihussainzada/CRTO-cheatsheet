The ESC2 privilege escalation vulnerability occurs when an attacker can enrol for a certificate that has either the _Any Purpose_ EKU or blank/empty EKUs (which is treated as _Subordinate CA_).  The resulting certificate can be used in place of any EKU, without restriction.
```
execute-assembly C:\Tools\Certify\Certify\bin\Release\Certify.exe enum-templates --filter-enabled --filter-vulnerable --hide-admins --quiet
```

Since the certificate can be used for any purpose, you can use it to mimic the abuse for [ESC3](https://www.zeropointsecurity.co.uk/path-player?courseid=red-team-ops&unit=699c5532a8886f37da0abe72).  If **ENROLLEE_SUPPLIES_SUBJECT** is enabled, then you can mimic [ESC1](https://www.zeropointsecurity.co.uk/path-player?courseid=red-team-ops&unit=699c298c2ea2401a520730cd) instead.
