Kerberos "delegation" is a feature that allows one principal to request access to resources on behalf of another principal.

It's enabled by setting a flag called `TRUSTED_FOR_DELEGATION` on the UserAccountControl attribute of the computer object.
```
ldapsearch (&(samAccountType=805306369)(userAccountControl:1.2.840.113556.1.4.803:=524288)) --attributes samaccountname
```
```
sAMAccountName: CONT-DC-1$
sAMAccountName: CONT-WEB-1$
```

> Domain controllers are always configured with unconstrained delegation, but this isn't much of an issue since having local admin access to a domain controller is pretty much game over anyway.

- So you need to be local admin to a machine.
- Steal that users ticket, and get a beacon into it with `jump` command.

If an adversary can compromise a computer configured for unconstrained delegation, they can extract these TGTs from memory and use them to request service tickets on behalf of those users to any other service in the entire domain.

Rubeus has a `monitor` command that periodically captures and displays TGTs as users authenticate to a service.
```
execute-assembly C:\Tools\Rubeus\Rubeus\bin\Release\Rubeus.exe monitor /nowrap
```
To terminate Rubeus, use the `jobs` and `jobkill` commands.
